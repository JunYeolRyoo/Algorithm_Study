``` python
import heapq
def to_int(time):
    return int(time[:2]) * 60 + int(time[3:])
def solution(book_time):
    answer = 0
    book_time.sort()
    heap = [float("inf")]
    for b in book_time:
        start = to_int(b[0])
        end = to_int(b[1])
        if start >= heap[0]:
            heapq.heappop(heap)
        else:
            answer += 1
        heapq.heappush(heap,end+10)
    return answer
```

**Time Complexity: O(N log N)<br>**
**Space Complexity: O(N)**
